# Folder Tangkapan Layar (Screenshots) Laporan E2E ActiveHub

Simpan file gambar tangkapan layar Anda di dalam folder ini dengan penamaan berikut:

1. `01-terminal-execution.png` -> Tangkapan layar terminal saat menjalankan `npx playwright test`.
2. `02-html-report.png` -> Tangkapan layar browser saat membuka `npx playwright show-report`.
3. `03-trace-viewer.png` -> Tangkapan layar browser saat membuka Trace Viewer Playwright.
4. `04-github-actions-summary.png` -> Tangkapan layar halaman workflow run (centang hijau) di tab Actions GitHub.
5. `05-github-actions-job-logs.png` -> Tangkapan layar log langkah job di GitHub Actions.
6. `06-github-actions-artifacts.png` -> Tangkapan layar bagian Artifacts di GitHub Actions.
7. `07-playwright-ui-mode.png` (opsional) -> Tangkapan layar UI Mode `npx playwright test --ui`.

Gambar-gambar ini akan otomatis muncul pada dokumen `LAPORAN_PBL_E2E_TESTING_ACTIVEHUB.md`.
